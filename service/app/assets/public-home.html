Perguntas diretas

Sem promessa nebulosa.

Você precisa saber exatamente qual caminho está comprando. A gente deixa provider, limites e responsabilidades visíveis.

O Mago Bot é a API oficial do WhatsApp?

O Mago é a camada de produto e governança. Meta Cloud é o provider oficial quando configurado. Evolution é um provider de compatibilidade e tem garantias diferentes.

Posso começar com Evolution?

Sim, para piloto assistido e operações opt-in dentro das regras aplicáveis. A sessão pode exigir QR, reconexão ou intervenção do operador; isso aparece no health e no lifecycle.

Preciso mudar minha integração ao trocar de provider?

Não no contrato Mago: projeto, API key, quotas, eventos e auditoria permanecem no control plane. As capacidades e limites específicos do provider continuam explícitos.

O que acontece quando uma mensagem falha?

O Mago classifica o erro, respeita idempotência, aplica retry quando seguro e registra o evento para diagnóstico. O cliente não recebe um “deu ruim” sem contexto.
