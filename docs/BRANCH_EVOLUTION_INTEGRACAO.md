# Branch `evolution/integracao`

Branch dedicada à integração com a Evolution API, sessões, instâncias, QR Code, webhooks, filas, Redis, PostgreSQL e testes de reconexão.

A versão de produção atualmente fixada é `evoapicloud/evolution-api:v2.3.7`. O webhook global permanece desligado até existir um adaptador validado para o Mago Bot.
